# Agent Instructions

## Do Not Read Archived SDK Audit Lists

Do not read files in:

`execution-logs/DO-NOT-READ-SDK-AUDIT-ARCHIVE/`

Those files are historical SDK-AUDIT issue inventories, readiness audits, and prior remediation plans. They contain stale prior findings and remediation lists that can mislead future work.

For current SDK/tool-gateway context, use the active source code, tests, current runbooks, threat model, and targeted implementation plans instead.
